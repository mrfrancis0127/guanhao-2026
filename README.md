## 🎨 與 許泰祥網站的設計差異

這個網站刻意做得「**更專業、更克制、更現代**」，與 許泰祥版的「溫暖、親民」風格做出區隔：

| 維度 | 泰祥版 | 尚裕版 |
|---|---|---|
| 整體調性 | 溫暖、親民、在地之子 | 專業、克制、新世代鄉政 |
| 色彩 | 青色 + 奶油色 | 青色 + 深石墨 + 冷白底 |
| 字體 | 較圓潤 | 嚴謹的 Inter 等寬 + Noto Serif TC |
| Hero 照片 | 去背 + 旋轉光環裝飾 | 框景式 + 幾何錯位色塊 |
| 政見呈現 | 卡片浮起、彩色 icon | 表格式、極簡編號、深色 hover |
| 排版 | 自由、有機 | 強烈的網格與排版規則 |
| 案號標示 | 直接 | 編輯排版風 (01 / 02 / FIELD NOTES) |

## 🚀 部署到網路上

### 方法一：Netlify Drop（**最快**）

1. 解壓資料夾
2. 打開 👉 https://app.netlify.com/drop
3. 整個資料夾拖進去
4. 等幾秒，得到網址（如 `xxx.netlify.app`）

⚠️ 不註冊的話 24 小時後消失。註冊免費帳號即可保留。

### 方法二：Netlify 帳號（永久免費）

到 https://app.netlify.com/signup 註冊 → Add new site → Deploy manually → 拖入資料夾。

可在 Site settings 改子網域名稱，例如 `hsu-shangyu.netlify.app`。

## 🔧 後續修改建議

### 新增照片到「在地足跡」

在 `index.html` 中找到 `<div class="footprint-empty">` 整段，可以替換成跟泰祥網站一樣的 `gallery-grid` 結構。需要 3 張照片時，告訴設計師「依照泰祥版的 gallery 結構複製過來」。

### 客製主色

如果之後想微調青色色調，在 CSS 裡找到：
```css
:root {
  --primary: #14908A;
  --primary-dark: #0C6E68;
}
```
換掉這兩個值即可全站變色。
